Configuration requise

Créez un fichier .env à la racine du projet avec :

CMS_PASSWORD=votre-mot-de-passe

puis relancez le serveur (npm start).

Connecter GitHub

Le site est hébergé sur GitHub : le CMS y enregistre directement vos modifications. Il faut pour cela un jeton d'accès, à créer une seule fois.

  1. Ouvrez github.com → Fine-grained token.
  2. Repository access : Only select repositories → choisissez le dépôt du site.
  3. Permissions → Contents : Read and write (et Pages : Read pour suivre la mise en ligne).
  4. Cliquez Generate token, copiez-le et collez-le ci-dessous.

Le jeton reste uniquement dans ce navigateur. Utilisez « Déconnexion » sur un ordinateur partagé.
